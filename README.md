# Paragon Clicker (暗黑破坏神 4 巅峰盘全自动加点与智能规划器)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%2F11-blue)](https://www.microsoft.com/windows)

**Paragon Clicker** 是一款专为《暗黑破坏神 IV》玩家设计的高效巅峰加点辅助工具。通过深度整合暗黑核（D2Core）配装规划数据，实现**点数不足时智能求解最优路线**、**游戏盘面秒级自动视觉识别定位**，以及**全自动跨盘点击、选盘、按角度旋转、附接与 5 盘上限自动确认的端到端流水线**。

无需繁琐的手动框选与逐个板块翻找，只需按下 **`[F8]`**，全流程一键搞定。

---

## 🌟 核心功能

### 1. 🔗 跨盘全自动流水线 (End-to-End Multi-Board Pipeline)
传统巅峰加点往往需要点完一盘后手动找门、翻页选盘、核对旋转角度、附接后再重新对位。本项目实现了完整的跨盘自动化闭环：
- **拓扑出口门自动点击**：当前盘所有目标节点点满后，程序自动解算相邻盘连接方向（上/下/左/右），精准点击出口门弹出面板选项；
- **原生 OCR 盘名识别与选盘**：调取 Windows 系统原生 `Windows.Media.Ocr` 引擎，毫秒级识别候选面板标题，自动点击切换箭头找到目标盘面；
- **暗黑核旋转参数对齐**：进入预览模式后，自动读取 BD 中的顺时针旋转次数（0~3 次），驱动游戏点击【旋转面板】精确转至对应朝向；
- **自动附接与第 5 盘上限确认**：自动点击【附接面板】；当附接最后一个（第 5 个）盘弹出“达到 5 面板上限”模态警告框时，程序能**自动识别警告弹窗并点击【确认】**；
- **新盘面无缝接续**：附接完成后自动锁定新盘面物理坐标，直接开始下一盘节点的加点，实现真正的一键点满全部 5 盘！

### 2. 🎯 智能视觉定位（免手动框选）
- **一维红通道色度投影**：基于暗黑 4 巅峰盘特有的红色外边框特征，快速捕捉游戏窗口客户区并定位 21×21 盘面物理坐标；
- **告别手动选区**：开启游戏后无需手动拉框对齐，程序自动完成亚像素级格点映射；
- **辅助预览**：同时保留了 21×21 半透明悬浮网格预览和手动微调框选功能，方便用户随时核验点击精度。

### 3. ⚡ 巅峰点数最优路径规划 (Optimal Point Progression)
- **等级未满时的最优收益**：当角色处于升级阶段、可用巅峰点少于 BD 设定的全满点数时（例如仅有 120/160 点），内置规划器能自动挑选收益最大化的连通路径；
- **数学建模与拓扑约束**：采用混合整数规划（MIP）结合单商品流网络与支配树剪枝，严格保证加点序列从起点单源连通，支持传奇节点、雕文孔、稀有属性加成；
- **多种策略画像**：支持“综合均衡”、“核心输出”、“极端生存”多种加权模式；
- **一键自动化**：当填写的可用点数小于 BD 全满点数时，点击一键加点将**直接在后台自动计算最优路径并立即启动加点**，彻底省去手动操作。

### 4. 🚀 极简一键交互与全局热键
- **`[F8]` 一键开始加点**：自动检测点数并优化、自动激活游戏、自动定位盘面、自动连盘加点；
- **`[F7]` 自动识别盘面**：单独执行游戏巅峰盘红框识别定位；
- **`[F9]` 紧急停止**：在任何阶段均可瞬时强行中止所有鼠标与键盘动作。

### 5. 🛡️ 双重防失控安全保护 (Fail-Safe)
- 全局热键 `[F9]` 瞬时切断；
- **硬件级鼠标防失控**：加点执行过程中，只要将鼠标快速甩至屏幕最左上角 `(0, 0)`，程序将即刻触发安全机制并中止一切操作。

### 6. 🪶 纯净原生、绿色免安装
- 基于 Rust 原生编写，单个独立可执行文件（约 6.8 MB）；
- 启动迅速，内存占用极低；
- 零外部运行时依赖，不需要配置 Python 环境或安装大型第三方 OCR/求解器包，解压即用。

## 📖 使用指南

### 1. 准备工作
1. 启动 `paragon-clicker-rust.exe`；
2. 启动《暗黑破坏神 IV》，在游戏中打开角色**巅峰盘界面**（建议游戏采用无边框全屏或窗口模式）。

### 2. 操作步骤
```
[1. 粘贴链接] --> [2. 设定当前点数] --> [3. 按 F8 一键加点] --> [4. 全程全自动完成]
```
1. **解析配装**：在输入框中粘贴暗黑核 BD 链接（支持短链如 `https://www.d2core.com/d4/planner?bd=1Tok` 或完整变体链接），点击「🔍 解析链接」，并在下拉框中选择要应用的变体；
2. **设定可用点数**：在「当前可用巅峰点」中输入你目前拥有的点数（若已满级保持默认即可；若填入小于 BD 全满的点数，程序会自动计算最优路线）；
3. **一键开始加点**：直接按下键盘 **`[F8]`**（或点击界面第一位的 **「▶ 🚀 一键开始加点 (F8)」**）；
4. **全自动执行**：程序将自动激活游戏窗口、定位盘面、极速加点、自动选盘并旋转附接，直至全部设定点数分配完毕！

> 💡 **温馨提示**：加点过程中请勿手动移动鼠标或切换其他应用；如需紧急停止，随时按键盘 **`[F9]`** 或甩鼠标到**屏幕最左上角 `(0, 0)`** 即可。

## 🛠️ 项目架构

```
src/
├── d2core/             # 暗黑核 API 交互、构筑解析与 21×21 盘面几何变换
│   ├── api.rs          # 云函数签名与构筑数据拉取
│   ├── geometry.rs     # 盘面旋转换算与出口门相对偏移
│   ├── graph.rs        # 跨盘 BFS 连通性校验与拓扑序构建
│   ├── model.rs        # 数据模型 (Board, Step, ClickPoint 等)
│   └── parser.rs       # 链接与参数解析
│
├── optimizer/          # 巅峰点数受限时的路径优化器
│   ├── glyph.rs        # 雕文辐射范围与加成结算
│   ├── score.rs        # 节点属性价值评分与加权画像
│   ├── solver.rs       # 单商品流网络 + 支配树约束 + 分支定界求解
│   └── types.rs        # 策略选项与统计结构
│
├── automation/         # 自动化控制、图像视觉与安全保护
│   ├── board_connector.rs # 跨盘出口门点击、选盘、旋转、附接与弹窗确认状态机
│   ├── vision.rs       # 游戏窗口抓取与 1D 红通道色度投影智能定位
│   ├── ocr.rs          # Windows 原生 OCR 文本识别
│   ├── input.rs        # Windows SendInput 模拟点击与鼠标防失控保护
│   ├── hotkey.rs       # Win32 全局热键监听 (F7/F8/F9)
│   ├── overlay.rs      # 原生半透明拖拽框选与网格预览窗口
│   └── process.rs      # 游戏窗口探测与前台激活
│
├── ui/                 # 现代化图形用户界面
│   └── app.rs          # 界面状态驱动、异步通道调度与一键流水线控制
│
└── main.rs             # 应用程序入口
```
